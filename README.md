# Product-Optimization-and-Revenue-analysis-for-Afficionado-Coffee-Roasters

## Project Overview
This project analyzes product-level sales performance to identify high-performing products, revenue contribution, and optimization opportunities. Various analytical techniques were applied to understand product demand and support inventory and pricing decisions.

## Objectives
- Analyze product-wise revenue.
- Identify top-selling products.
- Perform Pareto (80/20) analysis.
- Evaluate product contribution to total revenue.
- Recommend strategies for product optimization.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Project Workflow
1. Data Cleaning
2. Product-Level Analysis
3. Revenue Distribution
4. Pareto Analysis
5. Product Ranking
6. Visualization
7. Dashboard Development

## Key Insights
- A small percentage of products contributed to a major share of revenue.
- Several products generated consistently high sales.
- Product optimization opportunities were identified using Pareto analysis.
- Revenue concentration helps improve inventory planning.
